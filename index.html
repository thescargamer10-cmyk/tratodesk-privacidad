Aviso de privacidad

TratoDesk

Última actualización: 31 de octubre de 2026

TratoDesk es una herramienta de escritorio de uso interno para organizar y consultar conversaciones de ventas recibidas por la página de Facebook vinculada. Este aviso explica qué información se consulta y cómo se utiliza.

1. Responsable y contacto

La persona que administra la página de Facebook vinculada a TratoDesk, que opera bajo el nombre OfertasVipMex, es responsable del tratamiento descrito en este aviso. Para dudas, solicitudes de acceso, corrección o eliminación, envía un mensaje privado a esa misma página de Facebook e indica que tu solicitud se refiere a TratoDesk.

2. Información que se consulta

Por medio de las herramientas y API de Meta, TratoDesk puede consultar la información necesaria para identificar y atender una conversación:

  • El contenido de los mensajes que envías a la página.
  • El nombre y los identificadores básicos de tu perfil que Meta proporciona a la página.
  • Datos asociados a la conversación, como identificadores, fechas y estado de los mensajes.

No solicitamos contraseñas, datos de tarjetas ni información de pago por medio de TratoDesk.

3. Para qué se utiliza

La información se utiliza únicamente para revisar y organizar consultas sobre productos, responder preguntas de venta, dar seguimiento a conversaciones y atender pedidos relacionados con la página. TratoDesk no utiliza los mensajes para publicidad dirigida ni los vende o renta.

4. Uso de inteligencia artificial y comunicación automática

Actualmente TratoDesk solo consulta y muestra mensajes obtenidos de Meta. El contenido de las conversaciones no se envía a proveedores externos de inteligencia artificial y TratoDesk no responde automáticamente por medio de una IA.

5. Almacenamiento y conservación

TratoDesk es una aplicación de escritorio usada por quien administra la página; no es un servicio en la nube para otros vendedores. La información necesaria para organizar conversaciones puede conservarse en el equipo donde se ejecuta la aplicación y se limita a la atención y seguimiento de consultas de venta. No se aloja en un servidor propio de TratoDesk.

Los mensajes que permanecen en Facebook o Messenger están sujetos a las herramientas y políticas de Meta. Eliminar una copia local de TratoDesk no elimina por sí mismo el mensaje de Meta.

6. Con quién se comparte

La información se consulta a través de Meta y puede ser tratada por Meta conforme a sus propios términos y políticas. No compartimos el contenido de los mensajes con otros vendedores ni con proveedores de IA.

Este aviso se publica mediante GitHub Pages. GitHub informa que puede registrar la dirección IP de quienes visitan sitios Pages por motivos de seguridad. Consulta la Declaración de privacidad de GitHub y la Política de privacidad de Meta.

7. Solicitudes de acceso, corrección y eliminación

Puedes ejercer los derechos de acceso, rectificación, cancelación u oposición (ARCO), así como solicitar la eliminación de la información que esté bajo nuestro control enviando un mensaje privado a la página de Facebook vinculada a TratoDesk. Indica “Solicitud de privacidad de TratoDesk” y, para localizar la conversación, incluye la fecha aproximada y el perfil desde el que nos escribiste. Eliminaremos la copia local que esté bajo nuestro control cuando corresponda.

Para eliminar mensajes que permanecen en Facebook o Messenger, utiliza también las opciones de la propia plataforma. La solicitud enviada a la página no borra automáticamente la copia que Meta conserva.

8. Cambios a este aviso

Si cambia la forma en que TratoDesk accede, usa, almacena o comparte información, actualizaremos este aviso y su fecha. Si en el futuro se incorpora una función de inteligencia artificial o un nuevo proveedor, este aviso se actualizará antes de usarla con conversaciones.

Este aviso se aplica al uso de TratoDesk para gestionar conversaciones de la página vinculada. Para cualquier solicitud, utiliza el canal de contacto indicado arriba.
